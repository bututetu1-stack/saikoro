# 追加で必要な絵（レリック4枚・お守り2枚・敵3体）

下の文言を、画像生成 AI にそのまま貼り付けてください。画風は `art-requests-phase2.md` とそろえています。

## 入れ方

1. できた PNG を、ファイル名どおりに次のフォルダへ入れる。
   - `relic_*.png` → `Assets/_Project/Art/Relic`
   - `charm_*.png` → `Assets/_Project/Art/Charm`
   - `enemy_*.png` → `Assets/_Project/Art/Battle`
2. Unity で、取り込み設定が Multiple になっていたら Single に直す（Claude に「反映して」と頼めば直します）。
3. **SaiNoMichi → Build All Data**（レリック・お守り）と **SaiNoMichi → Update Art**（敵）を実行する。
