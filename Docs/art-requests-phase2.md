# フェーズ2で必要な絵（生成用の文言つき）

いまの絵（小鬼・鈴・攻撃の予告・野原の背景）に合わせた文言です。どれも **なくても動きます**（仮の図形・頭文字で表示）。届いた順に入れてください。

## 入れ方

1. 下の表の **ファイル名** で、**置き場所** のフォルダに PNG を入れる（Art/Charm は新しく作る）。
2. Unity で **SaiNoMichi → Build All Data**（レリック・お守りのアイコン）と **SaiNoMichi → Update Art**（敵・予告・背景）を実行。
3. コンソールに「まだない絵」が出るので、残りを確認できます。

## 共通の文言（毎回、先頭に付ける）

アイコン・敵（正方形・背景透過）：

> 和風の浮世絵風イラスト、和紙の質感、太く黒い輪郭線、温かみのある落ち着いた色（朱・金・藍・墨）、単体のモチーフを中央に大きく、背景は透過（なにもなし）、文字なし、正方形 1254×1254

背景（横長）：

> 和風の浮世絵風の風景画、和紙の質感、金色の雲（すやり霞）で上下を縁取る、中央は広く空けて淡い地面だけ（盤面やキャラクターを上に置くため）、文字なし、1536×1024

英語のほうが通りやすいツールなら：

> Japanese ukiyo-e style illustration, washi paper texture, bold black outlines, warm muted colors (vermilion, gold, indigo, sumi ink), single subject centered and large, transparent background, no text, square 1254x1254
