# フェーズ2で必要な絵（一括生成用の文言）

下の **一括生成の文言** を、画像生成 AI（ChatGPT など）にそのまま貼り付けてください。
必要なのは 47 枚（48〜52 は予備）です。途中で止まったら「続けて」と送れば、続きの番号から作ってくれます。

- どの絵もなくてもゲームは動きます（仮の図形・頭文字で表示）。
- 生成 AI はサイコロをうまく描けないので、**サイコロが描かれる図柄は使っていません**。
- 背景は、先に作った第1層の2枚（bg_map・bg_battle）も **同じ文言でまとめて作り直し**、7枚の画風をそろえます（金の雲の出方などがばらつかないように）。古い2枚は上書きしてかまいません。

## 入れ方

1. できた PNG を、ファイル名どおりに次のフォルダへ入れる。
   - `bg_map*.png` `bg_title.png` → `Assets/_Project/Art/Map`
   - `bg_battle*.png` `enemy_*.png` `intent_*.png` → `Assets/_Project/Art/Battle`
   - `relic_*.png` → `Assets/_Project/Art/Relic`
   - `charm_*.png` → `Assets/_Project/Art/Charm`（新しく作る）
2. Unity で **SaiNoMichi → Build All Data**（レリック・お守り）と **SaiNoMichi → Update Art**（背景・敵・予告）を実行。
3. コンソールの「まだない絵」で、残りを確認できます。
