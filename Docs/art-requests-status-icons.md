# 状態・特性のアイコン（13枚）

戦闘の HP の下・上に並ぶ印を、漢字1文字から絵にするための文言です。下の文言を画像生成 AI にそのまま貼り付けてください。

- 防御の印は、もうある `intent_block.png`（青い盾）を使っています。作る必要はありません。
- 絵がない印は、今までどおり漢字1文字で出ます。1枚ずつ入れても大丈夫です。

## 入れ方

1. できた PNG を `Assets/_Project/Art/Battle` に入れる。
2. Claude に「反映して」と頼む（取り込み設定を直して、**SaiNoMichi → Update Art** を実行します）。

## 生成の文言

```
和風ローグライクゲーム「賽ノ道」の、状態異常・敵の特性を表す小さなアイコンを、下の一覧の順番に1枚ずつ、全部で13枚作ってください。
1枚作るごとに、その絵のファイル名（例：status_strength.png）を書いてください。
途中で止まったら、私が「続けて」と言うので、続きの番号から作ってください。

【全部の絵に共通の画風】
・和風の浮世絵風イラスト。和紙の質感。太く黒い輪郭線。
・すでにある「青い盾」のアイコン（太い黒の縁取り＋白いふち＋中を一色で塗る）と同じ描き方にそろえる。
・文字・ロゴ・数字は入れない。
・サイコロ（立方体のさいころ）は絶対に描かない。

【アイコンの決まり】
・正方形 1254×1254、背景は透過（なにもなし）。
・モチーフを1つだけ、中央に大きく。周りに余白を少しだけ。
・ゲームでは 40px くらいのとても小さな大きさで表示するので、細かい描き込みはせず、太い形と、はっきりした1〜2色だけで、ひと目で見分けられるようにする。
・13枚とも、色がはっきり違うようにする（下の色の指定に従う）。

【一覧】
― 状態異常（プレイヤーにも敵にも付く） ―
1. status_strength.png：筋力。握りこぶしを高く突き上げた腕。色は山吹色（濃い黄色）。
2. status_weak.png：脱力。だらりと垂れ下がった、しおれた腕（力の抜けた手）。色は紫。
3. status_vulnerable.png：弱体。ひびが入って割れかけた盾、または胸当て。色は朱色（赤橙）。
4. status_frail.png：脆弱。ぼろぼろに欠けて崩れかけた木の板（弱った守り）。色は灰青色。
5. status_poison.png：毒。緑の液体が一滴したたる、毒の雫。色は若草色（明るい緑）。
6. status_fortify.png：堅守。石垣を積んだ城壁の一部。色は水色。
7. status_bind.png：縛り。きつく結ばれたしめ縄。色は薄紫。

― 敵の特性 ―
8. trait_thorns.png：棘。外側に鋭い棘がびっしり生えた丸いもの（栗のいがのような形）。色は赤。
9. trait_wall.png：鉄壁。鋲を打った分厚い鉄の門の扉。色は鉄色（青みがかった灰色）。
10. trait_ally.png：仲間思い。2つの拳を合わせた形（固い絆）。色は橙色。
11. trait_enrage.png：激昂。怒って燃え上がる炎と、つり上がった鬼の目。色は真っ赤。
12. trait_phase.png：変身。くるりと渦を巻く煙の中から角がのぞく。色は紫。
13. trait_invert.png：天邪鬼（裏返し）。上下が逆さまになった小さな鬼の面。色は赤紫。
```
