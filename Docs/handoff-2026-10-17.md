## 3. バランス（自動プレイ 600 ラン・段位0）

| 段階 | 踏破率 |
| --- | --- |
| 役なし（前日） | 49.7% |
| 役あり（敵の HP そのまま） | 74.5% |
| 役あり・敵の HP 140%（#233） | 50.7% |
| レリック6つ（#234） | 53.0% |
| 役を狙う自動プレイ（`AutoPlayer.aimHands`） | 54.8% |
| ダイス2つ（#237） | 54.5% |

- ゾロ目 +2 だけで約 15 ポイント上がる（いちばん出やすいため）。ゾロ目 +1・HP 125% でも同じくらい（50.8%）だが、役を目立たせるほうを選んだ。
- 戦闘の長さ（自動プレイ 300 ラン、1戦闘の平均ラウンド数）：役を入れる前 通常 5.2・強敵 約9・ボス 約12 → 今 通常 5.7・強敵 約10・ボス 約13。役で少しだけ長くなった（敵の HP を増やしたため）。仕様書の目安（通常戦 3〜4 ラウンド）より前から長いので、テンポが気になるなら敵の HP 全体を下げて、役の値も下げるのが手。
- 役を狙っても自動プレイでは少し上がるだけ。人が狙うともっと上がるかもしれないので、遊んでみて強すぎたら敵の HP（`DataBuilder.HandsHp`）か役の値（`DiceHands`）を下げる。
