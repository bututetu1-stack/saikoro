# 追加で必要な絵（ボスレリック4枚・お守り3枚）

下の文言を、画像生成 AI にそのまま貼り付けてください。画風は `art-requests-phase2.md` のアイコンとそろえています。

## 入れ方

1. できた PNG を、ファイル名どおりに次のフォルダへ入れる。
   - `relic_*.png` → `Assets/_Project/Art/Relic`
   - `charm_*.png` → `Assets/_Project/Art/Charm`
2. Unity で、取り込み設定が Multiple になっていたら Single に直す。
3. **SaiNoMichi → Build All Data** を実行する。
