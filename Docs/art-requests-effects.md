# 戦闘エフェクトの追加（8枚）

戦闘の演出を増やしたので、それぞれ専用のエフェクトの絵があると見分けやすくなります。下の文言を画像生成 AI にそのまま貼り付けてください。

- 絵がなくても動きます（今は、今までの斬撃・盾の絵の色を変えるか、キャラクターが光るだけ）。1枚ずつ入れても大丈夫です。
- 今ある `fx_slash.png`（赤い斬撃）・`fx_hit.png`・`fx_block.png`（青い六角形の防御壁）と同じ画風にそろえます。

## どこで使うか

| ファイル名 | 出る場面 |
| --- | --- |
| `fx_heal.png` | 回復したとき（血吸い賽・刻印「吸血」「薬」・天秤） |
| `fx_self_damage.png` | 自分のダイスで傷ついたとき（錆び賽の自傷） |
| `fx_poison.png` | 毒のダメージ・毒を受けたとき |
| `fx_buff.png` | 筋力が上がったとき（敵の強化・仲間を倒されて怒る） |
| `fx_debuff.png` | 脱力・弱体・脆弱を受けた／与えたとき |
| `fx_block_perfect.png` | 敵の攻撃を防ぎきったとき（金色の防御壁） |
| `fx_shield_break.png` | 防御が大きく破られたとき（割れた防御壁） |
| `fx_finish.png` | 敵にとどめを刺した一撃（金色の大きな斬撃） |

## 入れ方

1. できた PNG を `Assets/_Project/Art/Battle` に入れる。
2. Claude に「反映して」と頼む（取り込み設定を直して、**SaiNoMichi → Update Art** を実行します）。

## 生成の文言

```
和風ローグライクゲーム「賽ノ道」の、戦闘で一瞬だけ表示するエフェクトの絵を、下の一覧の順番に1枚ずつ、全部で8枚作ってください。
1枚作るごとに、その絵のファイル名（例：fx_heal.png）を書いてください。
途中で止まったら、私が「続けて」と言うので、続きの番号から作ってください。

【全部の絵に共通の画風】
・墨と水彩の筆致で描いた、和風のエフェクト。にじみ・しぶき・筆のかすれがある。
・光っている部分は白く飛ばし、周りに色がにじむように広がる（発光している感じ）。
・すでにある「赤い斬撃（筆で払ったような赤い一閃としぶき）」「青い六角形の防御壁（光る六角形の中に波の渦）」と同じ描き方にそろえる。
・文字・ロゴ・数字・人物・キャラクターは入れない。
・サイコロ（立方体のさいころ）は絶対に描かない。

【エフェクトの決まり】
・正方形 1254×1254、背景は透過（なにもなし）。白や黒の背景を塗らない。
・エフェクトは画面の中央に大きく、周りに少し余白。
・ゲームではキャラクターに重ねて、0.5秒くらいで広がって消える。形がひと目でわかるように、はっきりした形と色にする。
・8枚とも、色がはっきり違うようにする（下の色の指定に従う）。

【一覧】
1. fx_heal.png：回復。中心から柔らかく広がる若葉色（明るい緑）の光の輪と、ふわりと舞い上がる光の粒・小さな葉。やさしく温かい感じ。
2. fx_self_damage.png：自傷（錆びた刃で自分が傷つく）。赤茶色・錆色のぎざぎざした衝撃のしぶき。中心にひびのような亀裂。鉄錆の粉が飛び散る、にぶく痛そうな感じ。
3. fx_poison.png：毒。毒々しい黄緑と紫の、ぼこぼこ湧き上がる泡と煙。しずくが飛び散る。
4. fx_buff.png：筋力が上がる。下から上へ燃え上がる、山吹色（濃い黄色）と朱色の炎のようなオーラ。力がみなぎる感じ。
5. fx_debuff.png：弱らせる。上から下へ沈みこむ、紫と灰色の渦を巻く煙。重くまとわりつく、力が抜ける感じ。
6. fx_block_perfect.png：完璧な防御。すでにある「青い六角形の防御壁」と同じ形の六角形の光の壁を、金色・山吹色で。縁がまぶしく輝き、跳ね返った光の線が放射状に飛ぶ。傷ひとつない。
7. fx_shield_break.png：防御が破られる。すでにある「六角形の防御壁」と同じ形が、赤く染まって大きくひび割れ、破片が外へ飛び散っている。割れ目から赤い光がもれる。
8. fx_finish.png：とどめの一撃。すでにある「赤い斬撃」より大きく太い、金色の筆の一閃。斜めに画面を横切り、金と白の光がはじけ、桜の花びらのような金色の火の粉が舞う。
```
