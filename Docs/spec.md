# すごろくローグライク 企画仕様書

作成日: 2026-10-07 / 元ドキュメント: Claude Docs「すごろくローグライク 企画仕様書」（このファイルはその書き出し）

## 1. ゲーム概要

仮タイトル「賽ノ道（さいのみち）」は、サイコロを育てて出目で道を選ぶ、1ラン30〜40分のすごろく型ローグライクです。

| 項目 | 内容 |
| --- | --- |
| ジャンル | シングルプレイ・ターン制ローグライク（ダイスビルド＋すごろく） |
| 開発環境 | Unity 2D（C#）、まずPC向け |
| 1ランの長さ | 3層・30〜40分 |
| 世界観（仮） | 和風の双六絵巻。賽・鬼・狐・祠などのモチーフ |
| 参考作品 | Slay the Spire（マップ・インテント）、Dicey Dungeons（ダイス戦闘）、Loop Hero |

### 面白さの核（3本柱）

1. **出目の確率を自分で設計する**：ダイスの入手・改造・削除で、運任せのサイコロを「狙える道具」に変える。
2. **移動と戦闘で同じダイスを取り合う**：一度使ったダイスは使用済みになるため、「今の移動で強い賽を使うか、戦闘に温存するか」が毎ターン悩みどころになる。
3. **盤面を読んで止まるマスを狙う**：マップは全体が見えており、ダイスの出目の範囲から「どこに止まれるか」を計算して進む。

### 決定済み事項

- 戦闘もダイスで行い、出目を攻撃か防御に割り振る
- マスの効果は止まったときに発動する（一部のマスのみ通過時にも発動）
- 進めるのは前方向だけ（イベントによる強制移動は例外）
- 急かす仕組み（ターン制限など）は入れない
- ボスマスでは出目が余っても必ず止まる

## 2. ゲームの流れ

1ランは3層構成で、各層の最後にいるボスを倒すと次の層へ進み、第3層のボスを倒すとクリアです。

（図：1ターンの流れ）
```
[ダイスを選ぶ] → [振る] → [出目ぶん進む] → [マスの効果]
                                              ├─ 戦闘マス → [戦闘] →(勝利)→ [報酬を選ぶ] ─┐
                                              └─ その他（ショップ・イベント・空白など）────┴→ 次のターンへ
ダイスポーチ: [使用可能] --使う--> [使用済み] --0個になったら全部戻る（リフレッシュ）--> [使用可能]
  移動で1個、戦闘で1ラウンド最大2個、どちらもポーチから使う
```

移動で使ったダイスも、戦闘で使ったダイスも同じ「使用済み」に入るため、戦闘の前後の移動がそのまま戦闘の難しさにつながります。

### 層の構成

| 層 | 舞台（仮） | マス数 | ボス |
| --- | --- | --- | --- |
| 第1層 | 野原の街道 | 36 | 双六の番人 |
| 第2層 | 鍾乳洞 | 40 | 大顎（おおあご） |
| 第3層 | 鬼の城 | 44 | 賽の神・八面 |

層をクリアすると、HPが最大HPの30%回復し、全ダイスが使用可能に戻ります。

### 1ターンの流れ

1. **盤面を読む**：ポーチのダイスにカーソルを合わせると、そのダイスで止まりうるマスと確率が盤面上に表示される。
2. **ダイスを選ぶ**：使用可能なダイスから1個を選ぶ。
3. **振る**：出目が決まる。この時点で「振り直し」などのお守りを使える。
4. **進む**：出目の数だけ前に進む。分岐点は歩数を消費せず、その場で進む方向を選ぶ。通過効果のあるマスはここで発動する。
5. **マスの効果**：止まったマスの効果が発動する（戦闘・ショップ・イベントなど）。
6. 次のターンへ。ボスマスに着いたらボス戦。

### 勝敗条件

- **クリア**：第3層のボス「賽の神・八面」を倒す
- **ゲームオーバー**：HPが0になる
- リザルトでは到達層、総ターン数、倒した敵、最大ダメージを表示し、メタ進行用の経験値に換算する（第12章）

### リソース

| リソース | 初期値 | 上限 | 役割 |
| --- | --- | --- | --- |
| HP | 40 | 最大HP（初期40、増やせる） | 0でゲームオーバー |
| ゴールド | 50 | なし | ショップ・鍛冶・イベントで使う |
| ダイスポーチ | 4個 | 5枠（最大8枠） | 移動と戦闘に使うダイス |
| レリック | 0個 | なし | 常に効いているパッシブ効果 |
| お守り | 0個 | 3枠 | 1回だけ使える消耗品（第10章） |

## 3. ダイスシステム

ダイスは移動でも戦闘でも使うと「使用済み」になり、使用可能なダイスが0個になった瞬間に全部が戻る――このサイクルがゲームの中心です。

### ダイスの状態

| 状態 | 意味 | どうなると戻るか |
| --- | --- | --- |
| 使用可能 | 振れる | ― |
| 使用済み | 今は振れない | リフレッシュ、層クリア、一部の効果 |
| 封印 | 敵や罠によって振れない | 戦闘終了、または効果の終了時。リフレッシュでは戻らない |

### リフレッシュのルール

- 使用可能なダイスが0個になった瞬間、使用済みのダイスがすべて使用可能に戻る（移動中でも戦闘中でも同じ）。
- 戦闘で使ったダイスは、戦闘が終わっても使用済みのまま残る。これにより「戦闘で全力を出すと、その後の移動が不自由になる」という結果が生まれる。
- 「リフレッシュしたとき」に発動するレリックや刻印を用意し、サイクルを回すこと自体を戦略にできるようにする。

### 一度に使える数

| 場面 | 使える数 | 備考 |
| --- | --- | --- |
| 移動 | 1ターンに1個 | 複数振りできる効果は作らない（移動量の計算を単純に保つ） |
| 戦闘 | 1ラウンドに0〜2個 | レリックで最大3個。0個（パス）も可能で、その場合は防御0で敵の行動を受ける |

戦闘中に使用可能なダイスが1個だけのときは、その1個を振った時点でリフレッシュが起きるため、同じラウンド内でもう一つ選べます。このとき、今振ったばかりのダイスも使用可能に戻っているので、もう一度選んでかまいません。

### ポーチ

- 容量は初期5枠。レリック「大きな巾着」などで最大8枠まで増える。
- 満杯のときに新しいダイスを入手したら、どれか1個と入れ替えるか、受け取りをやめる。
- ダイスが多いほどリフレッシュまでの間隔が長くなり、強いダイスが回ってくる頻度が下がる。少数精鋭か、数で勝負するかがビルドの分かれ目になる。

### 初期構成

普通の賽・一二三賽・四五六賽 ＋ スターター1個（下の3つから選ぶ）で、4個・1枠空きの状態から始めます。
最初から「近くに止まる（一二三）」「遠くへ行く（四五六）」を選べるようにして、止まるマスを狙う余地を作ります（開発者の判断）。

| スターター | 出目 | 向いているプレイ |
| --- | --- | --- |
| 剣賽 | 1〜6（攻撃に回すと+2） | 攻撃で押し切る |
| 盾賽 | 1〜6（防御に回すと+2） | 戦闘を安定させる |
| 博打賽 | 0,0,0,10,10,10 | 一発逆転を狙う |

### 入手と削除

| 方法 | 入手 | 削除 |
| --- | --- | --- |
| 戦闘報酬 | 3個から1個を選ぶ（スキップすると10G） | ― |
| ショップ | 購入 | 75G（利用するたびに+25G） |
| 休憩マス | ― | ―（休憩マスは「回復」か「鍛える」。削除はショップ・イベントで行う） |
| イベント | 拾う・交換するなど | 捧げる、賭けるなど |
| 宝箱 | まれにアンコモン以上 | ― |

ポーチのダイスが2個未満になる削除はできません。

ダイスは全部6面で、コモン・アンコモン・レア・呪いの4種類に分かれます。強いダイスほど「移動で使うと戦闘で困る」形になるよう設計しています。

| ダイス | レア度 | 出目 | 特徴 | 価格 |
| --- | --- | --- | --- | --- |
| 普通の賽 | コモン | 1,2,3,4,5,6 | 基準。平均出目3.5 | 40G |

### 設計のメモ

- 普通の賽は「全部そこそこ」の基準です。他のコモンは、どこかが強くてどこかが弱い形にしています。
- 大賽とピンゾロ賽は、「戦闘専用」「移動の調整専用」と役割を分けた特殊枠です。大賽だけが使用可能で移動できないときは、そのターンは「1回休み」になり、大賽を使用済みにしてリフレッシュできます。
- 呪いダイスは入れ替えの対象にならず、削除するにはショップかイベントを使う必要があります。

## 5. ダイス鍛冶（面の改造）

鍛冶マスでは、ダイスの面を1つ選んで「刻印」を1つ付けられます。提示される3つの刻印から1つを選び、付けるダイスと面は自由に選べます。

### ルール

- 1つの面に付けられる効果刻印は1つ。新しい刻印を付けると上書きされる。
- 数値刻印は面の数字そのものを変えるため、効果刻印と併用できる。
- 面の数値は0〜9の範囲。
- 刻印はその面が出たときだけ効果を発揮する。「攻撃時」「防御時」は割り振り先、「移動時」は移動で振ったときを指す。
- ショップでも刻印を買える（第11章）。

### 数値刻印

| 刻印 | レア度 | 効果 |
| --- | --- | --- |
| 増強 | コモン | 面の数値+2 |
| 削り | コモン | 面の数値−1（移動の調整用） |
| 写し | アンコモン | 同じダイスの別の面の数値をコピーする |
| 金剛 | レア | 面の数値を9にする |

### 効果刻印

| 刻印 | レア度 | 発動 | 効果 |
| --- | --- | --- | --- |
| 刃 | コモン | 攻撃時 | 攻撃値+3 |
| 堅 | コモン | 防御時 | 防御値+3 |
| 小判 | コモン | いつでも | 3Gを得る |
| 薬 | コモン | いつでも | HPを2回復 |
| 毒針 | アンコモン | 攻撃時 | 毒3を与える |
| 吸血 | アンコモン | 攻撃時 | 与えたダメージの半分（切り捨て）を回復 |
| 崩し | アンコモン | 攻撃時 | 敵に脆弱1を与える |
| 足枷 | アンコモン | 攻撃時 | 敵の予告した攻撃値−3 |
| 再転 | アンコモン | いつでも | この面が出たら、振り直してもよい（1回） |
| 風 | アンコモン | 移動時 | 止まるマスを出目±1の中から選べる |
| 連鎖 | レア | いつでも | 使用済みのダイス1個を使用可能に戻す |
| 影縫い | レア | いつでも | このダイスを使用済みにしない |
| 両刃 | レア | 戦闘時 | 攻撃と防御の両方に同じ値を加える |
| 帰り道 | レア | 移動時 | 次の休憩マスかショップまで一気に進む（ボスマスは越えない） |

### 鍛冶の悩みどころ

- **どの面に付けるか**：6の面に刃を付ければ強いが、出る確率は1/6。細工賽なら6が2面あるため、写しで効率よく増やせる。
- **移動用に使うか、戦闘用に使うか**：風や帰り道は移動を改善し、刃や堅は戦闘を改善する。
- **どのダイスに付けるか**：よく使うダイスに集中するか、弱いダイスを補うか。

## 6. 戦闘システム

戦闘はラウンド制で、敵の予告（インテント）を見てからダイスを0〜2個振り、出目を攻撃と防御に割り振ります。通常戦は3〜4ラウンドで終わることを目安にします。

### 1ラウンドの手順

1. **予告**：敵が次の行動を表示する（例：攻撃8、防御6、封印）。防御の予告だけは、この時点ですぐに敵の防御値として反映される。
2. **選択**：使用可能なダイスから0〜2個を選ぶ。
3. **振る**：選んだダイスを同時に振る。出目を見てからお守りを使える。
4. **割り振り**：各ダイスの出目を「攻撃」か「防御」に置く。両方を同じ側に置いてもよい。敵が2体いるときは、攻撃に置いたダイスごとに狙う敵を選ぶ。
5. **攻撃の解決**：攻撃値が敵の防御値を削ってからHPを減らす。
6. **敵の行動**：予告どおりに行動する。攻撃は自分の防御値で軽減される。
7. **ラウンド終了**：毒などの状態異常を処理し、双方の防御値を0に戻す。

### 計算式

```latex
\text{攻撃値} = \left( \sum \text{攻撃に置いた出目} + \text{刻印・ダイス補正} + \text{筋力} \right) \times \text{弱体補正}
```

```latex
\text{受けるダメージ} = \max\left(0,\ \text{敵の攻撃値} \times \text{脆弱補正} - \text{防御値}\right)
```

弱体補正は0.75、脆弱補正は1.5で、どちらも端数は切り捨てます。

**例**：敵が「攻撃8」を予告。盾賽で4、普通の賽で5が出た。

- 盾賽を防御（4+2=6）、普通の賽を攻撃（5）に置く → 敵に5ダメージ、自分は2ダメージ
- 両方を攻撃（4−1+5=8）に置く → 敵に8ダメージ、自分は8ダメージ

### 状態異常

| 状態 | 対象 | 効果 | 減り方 |
| --- | --- | --- | --- |
| 毒 | 両方 | ラウンド終了時に毒の値だけダメージ（防御無視） | 毎ラウンド−1 |
| 筋力 | 両方 | 攻撃値に加算。攻撃に置いたダイス1個ごとではなく、合計に1回だけ | 戦闘終了まで持続 |
| 弱体 | 両方 | 攻撃値×0.75 | 毎ラウンド−1 |
| 脆弱 | 両方 | 受けるダメージ×1.5 | 毎ラウンド−1 |
| 堅守 | 両方 | 防御値がラウンド終了で消えず、半分残る | 毎ラウンド−1 |
| 封印 | プレイヤー | 指定されたダイスが戦闘終了まで振れない | 戦闘終了で解除 |
| 縛り | プレイヤー | 次のラウンド、振れるダイスが1個になる | 1ラウンドで解除 |

### その他のルール

- 敵は最大2体まで。
- 通常戦からは逃げられない（逃げたい場合はお守り「煙玉」を使う）。
- 戦闘に勝つと報酬画面へ移る（第11章）。戦闘で使ったダイスは使用済みのままです。

## 7. 敵の設計

敵は毎ラウンド「何をするか」を予告し、プレイヤーはそれを見てダイスの使い方を決めます。ダイスのサイクルそのものを邪魔する敵（封印・呪い）が、このゲームならではの要素です。

### インテント（予告）の種類

| インテント | 表示例 | 内容 |
| --- | --- | --- |
| 攻撃 | ⚔ 8 | 8ダメージ |
| 多段攻撃 | ⚔ 3×3 | 3ダメージを3回（防御は合計に対して効く） |
| 防御 | ⬢ 6 | 予告した時点で防御6を得る |
| 強化 | ↑ | 筋力を得る |
| 妨害 | ↓ | 弱体・脆弱・毒などを与える |
| 封印 | 🔒 | 使用可能なダイスのうち最も出目の平均が高いものを封印する |
| 呪い | ☠ | ポーチに欠け賽を加える |
| 溜め | … | 何もしない。次のラウンドに大攻撃 |
| 賽振り | 🎲 8 | 敵もサイコロを振る。振るのは予告の時点で、出目と行動は予告でわかる |

**方針：敵の行動はランダムをなるべく避け、予告で読めるようにする**（戦略性を保つため。2026-10-07 開発者の判断）。サイコロを振る敵も、振った結果を予告で見せる。

アイコンは仮のもので、ゲーム内では専用の絵に置き換えます。

### 第1層：野原の街道

| 敵 | 種類 | HP | 行動パターン |
| --- | --- | --- | --- |
| スライム | 通常 | 12 | 攻撃5 → 攻撃5 → 防御4 を繰り返す |
| 野ウサギ | 通常 | 8（1体で出るときは14） | 多段2×2 → 攻撃4 を繰り返す。2体で出ることが多い（フェーズ1は常に1体） |
| 小鬼 | 通常 | 15 | 強化（筋力+1）→ 攻撃6 → 攻撃6 |
| 化け茸 | 通常 | 14 | 弱体1を与える → 攻撃4 → 攻撃4 |
| 賽盗人 | エリート | 32 | 封印 → 攻撃7 → 多段3×3 を繰り返す |
| 双六の番人 | ボス | 55 | 下記 |

### 第2層：鍾乳洞

| 敵 | 種類 | HP | 行動パターン |
| --- | --- | --- | --- |
| 大蝙蝠 | 通常 | 16 | 多段3×2 を繰り返す |
| 骸骨兵 | 通常 | 24 | 防御8 → 攻撃9 |

**大顎**：「攻撃10 → 封印×2 → 溜め → 攻撃25」の4ラウンド周期。溜めのラウンドに合計12以上のダメージを与えると「怯み」状態になり、大攻撃が中止される。封印で強いダイスを奪われた状態で、溜めを止めるか備えるかを選ばせる。

## 8. マップとマス

各層の盤面は「分かれては合流する」一方通行の道で、毎回ランダムに生成されます。盤面全体は最初から見えており、「どのダイスでどこに止まれるか」を計算して進むのが基本の遊び方です。

（図：1層の盤面の形・模式図）
```
スタート ●─●─●─●─◆分岐(4〜7マス目)
            ├ 長い道：ショップ・宝箱が多い（マス多め）─┐
            ├ 標準の道 ──────────────────────┤
            └ 短い道：戦闘・罠が多い（マス少なめ）───┘合流 ─●─●─◆再び分岐
                 ├ 上の道 ─┐
                 └ 下の道 ─┘合流 ─■休憩かショップ（ボスの3〜6マス手前に必ず）─●─●─【ボス】
```

分岐ごとに道の長さと中身が違うため、「どの道に入るか」と「どのダイスで入るか」を同時に考えることになります。

### マスの種類と出現率

| マス | 効果 | 第1層 | 第2層 | 第3層 |
| --- | --- | --- | --- | --- |
| 戦闘 | 通常の敵と戦う | 30% | 30% | 30% |
| イベント（？） | 選択肢つきのイベント（第9章） | 25% | 22% | 20% |
| 罠 | ダメージ、封印、呪いなど | 7% | 10% | 11% |
| 休憩 | 「休む」（HPを最大HPの30%回復）か「鍛える」（鍛冶と同じく刻印を1つ付ける）のどちらか（Slay the Spire の焚き火と同じ形） | 10% | 9% | 8% |
| 宝箱 | ゴールド、レリック、まれにダイス | 12% | 12% | 12% |
| ショップ | ダイス、レリック、刻印、お守りを買う | 7% | 7% | 7% |
| 鍛冶 | ダイスの面に刻印を付ける（第5章） | 7% | 7% | 7% |
| エリート | 強敵。勝つとレリックが確定 | 2% | 3% | 5% |
| ボス | 層の最後。必ず止まる | ― | ― | ― |

何も起きない「空白」マスは置かない（止まっても何もないのは退屈なため。スタート地点だけは空白）。第2・3層の値は仮。

### 通過しても効果があるマス

上の表とは別に、1層に2〜3個だけ置きます（固定でない戦闘・イベント・宝箱のマスと置き換える）。止まった場合は効果が2倍になります。

| マス | 通過時の効果 |
| --- | --- |
| 祠 | 5Gを得る |
| 関所 | 10Gを払う。払えなければ5ダメージ |
| 茶屋 | HP3回復 |
| 賽場 | 使用済みのダイス1個を使用可能に戻す |

### 盤面の形

- 1層は36〜44マス（平均出目3.5なら約11回止まる長さ）。スタートから一本道で始まり、4〜6マス目で3本に分かれる。
- 分かれた道は長さを揃えない。短い道（戦闘や罠が多い）・標準の道・長い道（ショップや宝箱が多い）を用意し、「急ぐか、寄り道するか」を選ばせる。
- 分かれて合流するのを3回くり返す（3本 → 3本 → 2本）。ボスの手前で必ず1本に合流する。
- 並んだ道どうしは、途中の横道（隣り合う道の組ごとに1本）でつながる。出目を見てから乗り換えて、止まるマスを選べる。横道も前にしか進まない。
- （開発者の判断：止まるマスにプレイヤーの裁量を持たせるため、分岐を増やし横道を足した）

### 生成の手順

1. **骨組み**：分岐点と合流点の位置を決め、各区間の道の本数と長さを決める。
2. **固定マスを置く**：ボスの3〜6マス手前に休憩かショップを1つ以上、各層の中盤に鍛冶を最低1つ置く。
3. **抽選**：残りのマスを上の出現率で抽選する。
4. **制約チェック**：下のルールに違反したマスだけを引き直す。
5. **検証**：普通の賽だけで進んだ場合にショップか休憩に1回も止まれない確率をシミュレーションで計算し、30%を超えたら作り直す。

### 配置ルール

- 各層の最初の5マスには戦闘を1つまで。エリートと罠は置かない。
- 同じ種類のマスは2つまでしか連続しない。
- ショップ同士は6マス以上離す。
- エリートの前後1マスは戦闘・エリート・罠にしない（狙って避けられるように）。
- ボス直前の1マスは休憩にしない（確実に回復できると緊張感がなくなるため）。

### マップの見え方

- マスの種類はすべて見える。ただしイベントの中身、宝箱の中身、戦闘の敵の種類は止まるまでわからない。
- レリック「地図師の矢立」で、イベントと敵の中身が見えるようになる。

## 9. イベント

イベントは「すごろくらしさ」を一番出せる場所です。「1回休み」「3マス進む」「振り出しに戻る」などの定番ネタを、リスクと報酬のある選択肢として入れます。

### 設計方針

- 選択肢は2〜3個。必ず「何もしない」か、それに近い安全な選択肢を含める。
- できるだけダイスに関わる内容にする（振って判定する、ダイスを賭ける、ダイスを変形させる）。
- 「振って判定」では、振るダイスをプレイヤーが選ぶ。そのダイスは使用済みになるため、ここでも移動との取り合いが起きる。
- 前進のみのルールの例外として、イベントでは後退やワープが起きてもよい。

### イベント一覧（初期の12種）

| イベント | 層 | 選択肢と結果 |
| --- | --- | --- |
| 路地裏の賭場 | 全層 | 20Gを賭けて丁か半を宣言し、ダイスを1個振る。当たれば40G ／ 立ち去る |
| 落ちている賽 | 全層 | 拾う：ランダムなコモンダイス ／ よく調べる：50%でアンコモン、50%で欠け賽 ／ 放っておく |
| 古びた祠 | 全層 | HP−8でランダムな刻印を1つ付ける ／ お参りしてHP+5 |
| 流しの職人 | 全層 | 30Gで、好きな面の数値を1〜6の好きな値に変える ／ 立ち去る |
| 道祖神の双子像 | 第2層〜 | ダイス1個を捧げると、別のダイス1個を複製（刻印ごと） ／ 立ち去る |

「振り出しの札」は、マスをもう一度回れる（戦闘やショップを追加で得られる）ため、強いビルドを作りたい人には大きな得になります。1ランに1回しか出ません。

## 12. メタ進行（ランをまたいだ成長）

数値が永続的に強くなる要素は入れず、「選択肢が増える」形の解放だけにします。勝てるようになった理由が「自分がうまくなったから」になるようにするためです。

### 旅人（プレイヤーキャラ）

| 旅人 | 初期ダイス | 固有の能力 | 解放条件 |
| --- | --- | --- | --- |
| 賽振り | 普通×3＋スターター1個（3択） | なし（基本の旅人） | 最初から |
| 博徒 | 普通×2＋博打賽＋丁賽 | 戦闘勝利時、持ち金の10%を利息として得る | 第2層に到達 |
| 細工師 | 普通×3（うち1個の6の面に刃） | 鍛冶マスで提示される刻印が4つに増える | 刻印を累計10個付ける |
| 山伏 | 一二三賽×2＋盾賽×2 | 休憩マスで「休む」と「鍛える」の両方ができる | 一度クリアする |

### アイテムプールの解放

- 最初はダイス10種・レリック15種・刻印10種程度に絞り、覚えやすくする。
- ラン終了時に「旅の経験値」（到達層・倒した敵・クリアで加算）を得て、一定量ごとに新しいダイスやレリックがプールに加わる。
- 図鑑で、見たことのあるダイス・刻印・レリック・敵を確認できる。

| 段位 | 追加される条件 |
| --- | --- |
| 1 | エリートのHP+20% |
| 2 | ショップの価格+10% |
| 3 | 初期の最大HP−5 |
| 4 | ボスのHP+15% |
| 5 | 欠け賽を持ってスタート |
| 6 | 休憩マスの回復量−25% |
| 7 | 通常の敵の攻撃+1 |
| 8 | 罠マスの出現率が1.5倍 |
| 9 | ボスの手前の休憩・ショップが保証されない |
| 10 | 賽の神・八面が第3形態を持つ（HP40以下で、毎ラウンドダイス1個を封印） |

## 13. UI・画面構成

一番大事なUIは「ダイスにカーソルを合わせると、止まりうるマスと確率が盤面に光る」機能です。これがあることで、運のゲームが読みのゲームになります。

### 画面一覧

| 画面 | 役割 |
| --- | --- |
| タイトル | 開始、続きから、図鑑、設定 |
| 旅人選択 | 旅人・スターターダイス・段位を選ぶ |
| マップ | 盤面を見てダイスを振る。ゲームの中心 |
| 戦闘 | ダイスを振って攻撃・防御に割り振る |
| 報酬 | ゴールド・ダイス・レリックを受け取る |
| ショップ／鍛冶／休憩／イベント | マップの上に重ねて表示する小画面 |
| リザルト | 到達層、経験値、解放したもの |

### マップ画面

- **上部バー**：HP、ゴールド、お守り（3枠）、レリックのアイコン列、現在の層。
- **中央**：盤面。横スクロールで、自分の駒が常に画面の左寄りに来る。ボスまでの残りマス数を表示。
- **下部トレイ**：ポーチのダイスを並べる。使用済みは暗くして右側に寄せ、「あと何個でリフレッシュか」が一目でわかるようにする。
- **ダイスの詳細**：ダイスにカーソルを合わせると、6面の展開図（数値と刻印）が出る。同時に盤面上で止まりうるマスが光り、確率が表示される。分岐をまたぐ場合は、両方の道の候補を光らせる。

### 戦闘画面

- **左**：自分（HP、防御値、状態異常）。**右**：敵（HP、防御値、状態異常、頭上にインテント）。
- **下部**：ダイストレイ。ダイスをクリックで選び、「振る」ボタンで振る。
- **中央**：「攻撃」と「防御」の2つの枠。振ったダイスをドラッグで入れる。入れた瞬間に「与えるダメージ／受けるダメージ」の予測を表示する。
- 「パス」ボタン（ダイスを温存してこのラウンドを過ごす）。押すと受けるダメージを確認表示する。

### 操作感と演出

- ダイスを振る演出は0.6秒程度。設定で「高速」「省略」を選べる。
- 駒は1マスずつ跳ねて進み、通過効果はその場で小さく表示する。
- リフレッシュ時はダイスが一斉に明るくなる演出を入れ、サイクルが回ったことをことさらに伝える。
- マウスだけでもキーボードだけでも操作できるようにする（将来のスマホ対応を見据え、ホバーに頼る情報は長押しでも見られるようにする）。

## 14. Unity実装設計

「データはScriptableObject、ラン中の状態は普通のC#クラス、効果はイベントフック」の3層に分けます。レリックや刻印を後からいくらでも足せるようにするのが一番の目的です。

### データ（ScriptableObject）

| クラス | 主な中身 |
| --- | --- |
| DiceData | ID、名前、レア度、初期の6面（数値＋刻印）、特殊フラグ（移動不可、改造不可など）、価格 |
| EngravingData | ID、名前、レア度、発動タイミング、効果リスト |
| RelicData | ID、名前、レア度、効果リスト、ボスレリックかどうか |
| CharmData | お守り。使える場面と効果 |
| EnemyData | HP、行動パターン（インテントの列）、特殊能力 |
| EventData | 本文、選択肢、各選択肢の結果 |
| LayerConfig | マス数、マスの出現率、出現する敵、ボス |

### ラン中の状態

```csharp
// レア度や初期の面はDiceDataを参照し、改造後の面は個体ごとに持つ
public class DiceInstance {
    public DiceData data;
    public Face[] faces = new Face[6];   // 鍛冶で書き換わる
    public DiceState state;              // Available / Used / Sealed
}

public struct Face {
    public int value;                    // 0〜9
    public EngravingData engraving;      // nullなら刻印なし
}

public class RunState {
    public int hp, maxHp, gold, layer;
    public List<DiceInstance> pouch;
    public int pouchCapacity = 5;
    public List<RelicData> relics;
    public List<CharmData> charms;
    public TileNode current;
    public int seed;
}
```

### 盤面（グラフ構造）

```csharp
public class TileNode {
    public int id;
    public TileType type;                // Empty, Battle, Event, Shop ...
    public bool passEffect;              // 通過でも発動するか
    public List<TileNode> next;          // 分岐点なら2〜3個
    public Vector2 position;             // 表示位置
}
```

「このダイスで止まりうるマス」は、各面の数値ごとにグラフをその歩数だけたどり（分岐では全方向を探索）、到達したマスに1/6ずつ確率を足して求めます。ボスマスに入ったらそこで止めます。

### 効果の仕組み（イベントフック）

レリック・刻印・状態異常はすべて「何が起きたときに、何をするか」で書きます。

```csharp
public enum Trigger {
    OnRoll, OnAssignAttack, OnAssignDefense, OnRoundStart, OnRoundEnd,
    OnBattleStart, OnBattleEnd, OnRefresh, OnMoveRolled, OnPassTile,
    OnStopTile, OnLayerStart, OnGoldGain
}

public abstract class EffectSO : ScriptableObject {
    public Trigger trigger;
    public abstract void Apply(EffectContext ctx);
}
```

- `EffectContext` には、振ったダイス、出た面、割り振り先、攻撃値などを入れて渡し、効果はその値を書き換える。
- `EffectBus` が発動タイミングごとに効果を集め、「刻印 → レリック → 状態異常」の順で実行する。
- 「攻撃+3」「毒を与える」などの部品をEffectSOとして作り、インスペクターで組み合わせてレリックを作る。

### ゲーム全体の状態遷移

`Map → Rolling → Moving → TileResolve →（Battle / Shop / Event / Rest / Forge）→ Reward → Map` をステートマシンで管理します。戦闘は別のステートマシン（`Intent → Select → Roll → Assign → Resolve → EnemyAct → RoundEnd`）を持ちます。

### その他

- **乱数**：ランのシードから「マップ生成」「戦闘」「報酬」の3つの乱数を分けて作る。戦闘で振り方を変えても報酬は変わらず、バグの再現もしやすい。
- **セーブ**：RunStateをJSON化して保存。ScriptableObjectは参照ではなくIDで保存する。マップ画面に戻るたびに自動保存。
- **バランス検証用の自動プレイ**：簡単なAI（脆弱でなければ攻撃を優先、など）で数千回ランを回し、戦闘の長さや受けるダメージを第11章の目標値と比べる。

## 15. 開発の進め方と未決事項

最初に確かめるべきは「使用済みサイクルで、移動と戦闘の取り合いが本当に面白いか」です。ここが面白くなければ、他を作り込んでも救えないため、最小構成から始めます。

### 開発フェーズ

1. **プロトタイプ**：直線の盤面20マス、マスは空白・戦闘・休憩の3種、ダイスは普通・四五六・一二三の3種、敵は2種。見た目は四角と数字だけでよい。
   - 合格条件：自分やC3の仲間が遊んで、「どのダイスを移動に使うか」で悩む場面が1プレイに何度もある。
2. **第1層の完成**：分岐マップの生成、全種類のマス、敵のインテント、ダイス8種、刻印6種、レリック10種、イベント5種、第1層のボス。
   - 合格条件：第1層だけで「もう一回」と思える。プレイ時間が10〜13分に収まる。
3. **全層の完成**：第2・第3層、全ダイス・刻印・レリック・イベント、セーブ。
   - 合格条件：自動プレイでバランスの目標値（第11章）におおむね収まる。
4. **仕上げ**：メタ進行、段位、絵・音・演出、チュートリアル。
