# 引き継ぎ 2026-11-09

前の引き継ぎは `Docs/handoff-2026-10-30.md`。

## 1. 頼まれたこと

Musio を使って、戦闘中とマップの BGM を作る。続けて、ボスと強敵の BGM も作る。

## 2. やったこと（#250）

- Musio Studio にはエージェント機能（MCP。`127.0.0.1:47820/mcp`、トークンは `%APPDATA%\Musio Studio\agent-token`）がある。ここへスクリプトから音符を書き込んで2曲作った。
  - マップ「旅路」：D の陽音階、92 BPM、約 83 秒。ハープを琴のように刻み、木管が笛のように旋律を吹く。
  - 戦闘「賽の勝負」：D の陰音階の旋律に短調の和音、152 BPM、約 63 秒。弦のスピッカート・大太鼓・金管。
- 続けて #252 で2曲作った。
  - 強敵「鬼気」：E の陰音階、138 BPM、約 70 秒。低い弦の刻みと 3+3+2 の金管の打ち込みで、ふつうの戦闘より重く。
  - ボス「神前の大一番」：C の陰音階、160 BPM、72 秒。低い金管の主題に弦が高く応え、最後に全員で主題。
- 手持ちの Musio の音源に和楽器（琴・尺八・和太鼓）はない。ハープ・木管・Toms（大太鼓）で和の雰囲気を出した。
- くり返しても途切れないように切り出した WAV（48kHz・16bit）を `bgm_map.wav` / `bgm_battle.wav` / `bgm_elite.wav` / `bgm_boss.wav` として入れ、前の mp3 は消した（git の履歴には残る）。タイトルの曲はそのまま。
- 作り直しの手順とスクリプトは `Tools/musio/README.md`。Musio Studio の Songs に「SaiNoMichi Map」「Battle」「Elite」「Boss」として曲が残っている。

## 3. 確かめたこと

- Update Art で UIArt に入る。
- プレイモードで タイトル → マップ → 戦闘 → 強敵 → ボスと進み、それぞれ新しい曲がループで流れる（エラー 0）。
- 曲の出来は耳で確かめていない（Claude は音を聴けない）。音量の釣り合いは Musio の計測（各トラックの RMS・LUFS）で整えた。4曲とも約 −17 LUFS にそろえた。
- ボスのバスドラムは、オーケストラ打楽器の 36 番を使った（ほかの曲で使われていた番号。音を聴いて確かめてはいない）。

## 4. 気をつけること

- WAV なので mp3 より大きい（マップ 16MB・戦闘 12MB・強敵 13MB・ボス 14MB）。ビルドでは Vorbis（品質 50%）に圧縮されるので、WebGL の大きさはほとんど変わらない。
- 第2層・第3層だけ別の曲にしたいときは、`bgm_map_2.wav`・`bgm_battle_3.wav` のような名前で置けば Update Art が拾う（`SceneBuilder` が対応済み）。
