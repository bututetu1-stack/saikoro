# フェーズ1：第1層の完成

## 目的

第1層（野原の街道）を、仕様書どおりの中身で1層ぶん遊べるようにする。ダイスを集めて改造し、レリックで方向性を決め、分岐した道を選んで進む——ローグライクとしての「ビルドを作る楽しさ」があるかを確かめる。

## 合格条件

- 第1層だけで「もう一回」と思える。
- 1プレイ（第1層のボスまで）が 10〜13分 に収まる。
- EditMode テストがすべて通り、コンソールにエラーが出ていない。

## フェーズ0から引き継ぐこと

- フェーズ0の合格判定（移動に使うダイスで迷うか）は、フェーズ1を作りながら並行して遊んで確かめる。遊んだ記録の CSV は引き続き書き出す。
- 画面の作り方（UI をコードで組み立てる、演出は `UIAnim`、絵は `UIArt` に名前で登録）はそのまま使う。

## 作るもの

### 1. 効果の仕組み（仕様書 第14章）

- `Trigger` ＋ `EffectSO` ＋ `EffectContext` ＋ `EffectBus` のイベントフック方式。
- 刻印 → レリック → 状態異常 の順に実行する。
- 「攻撃+3」「防御+3」「毒を与える」「ゴールドを得る」「HPを回復」などの部品を EffectSO で作り、組み合わせてダイス・刻印・レリックを作る。

### 2. ダイス（8種）

| ダイス | 出目 | 特徴 |
| --- | --- | --- |
| 普通の賽 | 1,2,3,4,5,6 | 基準 |
| 一二三賽 | 1,1,2,2,3,3 | 移動の微調整 |
| 盾賽 | 1〜6 | 防御に回すと+2、攻撃に回すと−1 |
| 剣賽 | 1〜6 | 攻撃に回すと+2、防御に回すと−1 |
| 丁賽 | 2,2,4,4,6,6 | 偶数のみ |
| 半賽 | 1,1,3,3,5,5 | 奇数のみ |
| 博打賽 | 0,0,0,10,10,10 | 0か10 |
| 四五六賽 | 4,4,5,5,6,6 | 近くに止まれない |

- 初期構成：普通の賽×3 ＋ スターター1個（一二三賽・盾賽・博打賽から選ぶ）。ポーチは5枠。
- 開始時にスターターを選ぶ簡単な画面を作る。

### 3. ゴールドと報酬（仕様書 第11章）

- 初期ゴールド 50。
- 通常戦：12〜18G、ダイス3個から1個（コモン70%・アンコモン25%・レア5%）、スキップで10G。
- エリート：30〜40G、ダイス3択（コモン40%・アンコモン45%・レア15%）、レリック確定。
- ボス：60G、レアダイス3択。（ボスレリックはフェーズ2以降）
- ポーチが満杯なら、どれか1個と入れ替えるか受け取りをやめる。
- 報酬画面を作る。

### 4. 敵（第1層、仕様書 第7章）

| 敵 | 種類 | HP | 行動 |
| --- | --- | --- | --- |
| スライム | 通常 | 12 | 攻撃5 → 攻撃5 → 防御4 |
| 野ウサギ | 通常 | 8 | 多段2×2 か 攻撃4 をランダム |
| 小鬼 | 通常 | 15 | 強化（筋力+1）→ 攻撃6 → 攻撃6 |
| 化け茸 | 通常 | 14 | 弱体1 → 攻撃4 → 攻撃4 |
| 賽盗人 | エリート | 32 | 封印 → 攻撃7 → 多段3×3 |
| 双六の番人 | ボス | 55 | 賽振り（偶数なら×2の攻撃、奇数なら×2の防御）。4ラウンドごとに「振り出しに戻れ」 |

- 予告：多段攻撃・妨害（弱体）・封印・賽振り を追加。
- 状態異常：弱体・封印 を追加（筋力はフェーズ0で実装済み）。
- 出現ルール：最初の3戦は弱めの敵だけ、同じ敵は2戦続けない。
- フェーズ0の「ゴールの番人」は使わなくなる。

### 5. 盤面（仕様書 第8章）

- 1層 36〜44マス。スタートから一本道 → 4〜7マス目で2〜3本に分岐 → 中盤で合流 → もう一度分岐 → ボスの手前で合流。
- 分かれた道は長さを揃えない（短い道は戦闘・罠が多い、長い道はショップ・宝箱が多い）。
- 生成の手順：骨組み → 固定マス（ボスの3〜6マス手前に休憩かショップ、中盤に鍛冶）→ 出現率で抽選 → 制約チェック → 検証（普通の賽だけで進んでショップか休憩に1回も止まれない確率が30%を超えたら作り直す）。
- 配置ルール：仕様書 第8章「配置ルール」のとおり。
- マップ画面：分岐を上下に広げた2次元の配置、横スクロール（駒が左寄り）、分岐点で道を選ぶ、止まりうるマスの確率は分岐の両方に表示。

### 6. マス（全種類）

- 空白・戦闘・イベント・罠・休憩・宝箱・ショップ・鍛冶・エリート・ボス（出現率は仕様書 第8章の第1層の列）。
- 休憩：HPを最大HPの30%回復、またはダイスを1個無料で削除。
- 罠：ダメージ・封印・呪い（欠け賽）のどれか。
- 宝箱：30〜50G（半分の確率）、10%でアンコモン以上のダイス、半分の確率でレリック。
- 通過マス（1層に2〜3個）：祠・関所・茶屋・賽場。止まると効果2倍。

### 7. 鍛冶と刻印（6種、仕様書 第5章）

| 刻印 | 種類 | 効果 |
| --- | --- | --- |
| 増強 | 数値 | 面の数値+2 |
| 削り | 数値 | 面の数値−1 |
| 刃 | 効果 | 攻撃時、攻撃値+3 |
| 堅 | 効果 | 防御時、防御値+3 |
| 風 | 効果 | 移動時、止まるマスを出目±1から選べる |
| 小判 | 効果 | いつでも、3Gを得る |

- 鍛冶マス：3つの刻印から1つを選び、付けるダイスと面は自由に選ぶ。鍛冶画面を作る。

### 8. レリック（10種、仕様書 第10章）

草鞋、銭袋、木の盾、丁の札、半の札、小石、砥石、大きな巾着、鈴、早馬。

- 入手：エリート（確定）、宝箱、ショップ。
- 画面上部にアイコンを並べ、マウスを乗せると説明を出す。

### 9. ショップ（仕様書 第11章）

- ダイス3つ・レリック2つ・刻印2つ・ダイス削除（75G、利用するたびに+25G）。品物の1つは半額。
- お守りはフェーズ2以降（ショップにも並べない）。

### 10. イベント（5種、仕様書 第9章）

路地裏の賭場、落ちている賽、古びた祠、狐の嫁入り、韋駄天の足跡。

### 11. 層クリアと記録

- ボスを倒したらクリア画面（フェーズ1は第1層で終わり）。
- 遊んだ記録の CSV に、ゴールド・入手したダイス/レリック/刻印・止まったマスの種類を足す。
