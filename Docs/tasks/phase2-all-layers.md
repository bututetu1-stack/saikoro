# フェーズ2：全層の完成

## 目的

第1層から第3層のラスボスまで、仕様書の中身で1ランを通して遊べるようにする。層が進むごとに敵が手ごわくなり、ダイス・刻印・レリック・お守りがそろってビルドが育っていく——「1ランを最後まで遊びたくなるか」を確かめる。

## 合格条件（仕様書 第15章）

- 自動プレイで、バランスの目標値（仕様書 第11章）におおむね収まる。
  - 1ランの戦闘回数：通常戦 9〜10回、エリート 1〜2回、ボス 3回
  - 通常戦の長さ 3〜4ラウンド、ボス戦 7〜10ラウンド
  - 通常戦で受けるダメージ：最大HPの 10〜20%
- 人が遊んで、1ラン（第3層のボスまで）が 30〜40分 に収まる。
- 途中でやめても、続きから遊べる（セーブ）。
- EditMode テストがすべて通り、コンソールにエラーが出ていない。

## フェーズ1から引き継ぐこと

- 効果の仕組み（Trigger / EffectSO / EffectBus）、データの作り方（Build All Data のメニュー）、画面の作り方（UI をコードで組み立てる・UIArt に名前で登録・Sfx）はそのまま使う。
- フェーズ1の数値の調整（開発者が遊んだ CSV で行う）は、フェーズ2の最初と並行して進める。
- フェーズ1で決めたこと：敵の行動はランダムを避けて予告で読める形にする／イベントと罠はランダムでよい／休憩は「休む」か「鍛える」／ダイスの削除はショップとイベントだけ／空白マスなし／分岐3回＋横道＋行き先を直接選ぶ移動。

## 作るもの

### 1. 層の仕組み（仕様書 第2章・第8章）

- ランは3層。各層のボスを倒すと次の層へ。第3層のボスを倒したらクリア。
- 層をクリアすると、HPが最大HPの30%回復し、全ダイスが使用可能に戻る（仕様書 第2章）。
- ボスを倒したら報酬：60G・レアダイス3択・ボスレリック3択（作るもの 5）。
- 層ごとに：盤面の出現率（仕様書 第8章の第2層・第3層の列）、敵の顔ぶれ、背景の絵、マップの名前。
- 「層ごと」の効果（草鞋の回数・早馬・OnLayerStart）を、層が変わるたびに戻す。
- 敵の出現ルール：層が上がるごとに、前の層の敵も HP+50% でまれに出る。
- 画面上部に「第2層 鍾乳洞」のように層を表示する。層を移るときに短い演出を入れる。

### 2. 状態異常と敵の行動の追加（仕様書 第6章・第7章）

- 状態異常：脆弱（受けるダメージ×1.5）・堅守（防御が半分残る）・縛り（次のラウンド振れるダイスが1個）。
- 敵の行動：毒を与える／溜め（次のラウンドの大攻撃）／呪い（欠け賽を押し付ける）。
- 敵の特性：受けるダメージの上限（石の守護者）、HP が半分以下で攻撃2倍（首狩り）、前のラウンドのプレイヤーの攻撃値を返す（写し鏡）、溜めに一定以上のダメージで怯む（大顎）。
- 予告と状態異常の説明（マウスを乗せると出る）にも足す。

### 3. 第2層の敵（鍾乳洞）

大蝙蝠・骸骨兵・毒蜘蛛・岩の人形、エリート：写し鏡、ボス：大顎（攻撃10 → 封印×2 → 溜め → 攻撃25。溜めのラウンドに12以上与えると怯んで大攻撃が中止）。

### 4. 2体の敵との戦闘（開発者の判断で入れる）

- 敵が2体いる戦闘だけ、1ラウンドに振れるダイスが +1（2 → 3個）。4個にするとポーチがすぐ空になり、移動と戦闘の取り合いが崩れるため +1 にとどめる。
- 攻撃は自動で前の敵に当たる。倒しきって余ったダメージは次の敵へ。狙う敵を選ぶ操作は要らない。
- 敵をクリックすると、その敵を先に狙える（倒す順番が大事な場面のため。双子鬼など）。
- 防御は2体の攻撃の合計から引く。予告は2体ぶん並べる。
- 一緒に作るもの：薙ぎ賽（攻撃に置くと全部の敵に同じ値が当たる。新しいダイス）・レリック「古い賽筒」（振れる数+1）。
- 第1層の野ウサギを本来の「2体で出ることが多い」に戻すかは、これができてから決める。

### 5. 第3層の敵（鬼の城）

呪術師・鬼武者・双子鬼（22×2体。片方を倒すと残りが筋力+3）・石の守護者、エリート：首狩り、ラスボス：賽の神・八面（第1形態：8面ダイスの出目×2攻撃と×3防御を交互、出目は予告で見える／第2形態：HP90以下で「運命の書き換え」、プレイヤーの最も強いダイスの最大の面を戦闘中だけ1にする、以後3ラウンドごと）。

### 6. ボスレリック（5種、仕様書 第10章）

黄金の賽筒・重い王冠・呪われた双六盤・時の砂・縛りの腕輪。良い効果と悪い効果がある。ボスを倒したら3つから1つ選ぶ（スキップも可）。

### 7. 刻印（残り12種、仕様書 第5章）

- 数値刻印：写し（同じダイスの別の面をコピー。コピー元の面を選ぶ画面）・金剛（面を9に）。
- 効果刻印：薬・毒針・吸血・崩し・足枷・再転（振り直すか選ぶ）・連鎖・影縫い・両刃・帰り道。
- 鍛冶とショップの刻印にも並べる。

### 8. レリック（残り13種、仕様書 第10章）

薬草袋・ゾロ目の守り・積み石・毒壺・天秤・地図師の矢立・風車・貯金箱・運命の糸・六の加護・鍛冶の金槌・千里眼（古い賽筒は 4 で作る）。

- 地図師の矢立は、イベントと敵の中身を盤面を作るときに決めておき、マップで見えるようにする。
- 運命の糸（出目を好きな値に）と千里眼（振る前に出目が見える）は、専用の操作を作る。

### 9. お守り（7種、仕様書 第10章）

- 消耗品。最大3個。ショップで売る（ショップの品揃えに「お守り3つ」を足す）。イベントの報酬にもなる（狐の嫁入り「見送る」・迷子の子どもを本来の形に戻す）。
- 画面に持っているお守りを並べ、クリックで使う（移動の前・戦闘中など、使える場面だけ）。

### 10. イベント（残り7種、仕様書 第9章）

流しの職人・道祖神の双子像（第2層〜）・落とし穴・旅の商人・鬼の賽勝負（第2層〜）・迷子の子ども・振り出しの札（第1・第2層、1ランに1回）。

- イベントに「出る層」と「1ランに1回」を持たせる。

### 11. セーブと続きから

- ランの状態（ポーチ・面の刻印・レリック・お守り・HP・ゴールド・層・盤面・いまのマス・乱数の状態・成績）を保存する。
- 保存するのは「マップで操作を待っているとき」だけ（戦闘やイベントの途中は保存しない。戦闘の途中でやめたら、その戦闘の最初から）。
- 始めの画面に「続きから」「新しく始める」。

### 12. 自動プレイとバランス調整

- ロジックだけで1ランを最後まで進める自動プレイを作る（移動：止まりたいマスを狙う簡単な考え方、戦闘：予告を見て攻撃と防御を割り振る、報酬：決まった優先順位）。
- 何百ランか回して、戦闘回数・ラウンド数・受けるダメージ・クリア率・ゴールドを集計する。エディタのメニューから実行し、結果を CSV に書き出す。
- 目標値（合格条件）に入るように、敵の HP や攻撃・報酬・出現率を調整する。

## 決めたこと

- 2体の敵との戦闘を入れる。振れる数は2体のときだけ +1、攻撃は自動で前の敵へ（余りは次へ）、クリックで狙いを変えられる。薙ぎ賽と古い賽筒を一緒に作る（作るもの 4）。
- 仕様書にない新しいダイスは、自動プレイで足りない役割を見てから案を出す（作る順番 13）。
- `Phase0Game` / `Phase0Config` などの名前は、フェーズ2の最初に直す（作る順番 0）。
