## 2. 直したもの（#243）

| 内容 | 原因と直し方 |
| --- | --- |
| 続きからで真っ暗 | 「回想」はゲームの中に無い言葉なので、「続きから」のことと見た。戦闘の途中で中断した旅を続きから遊ぶと、マップを作ってすぐ戦闘を始める。そのときマップの浮かび上がりの演出が途中で止まり、透明のまま残って、戦闘のあと真っ暗になっていた。浮かび上がりの途中で画面が隠されたら見えている状態に戻すようにした（`UIAnim.FadeInGuard`）。同じ演出を使う画面すべてに効く |
| シードの「変える」が反応しない | 数字を打たないと何も起きなかった。空欄なら別のシードを引く・読めない文字なら理由を出す・全角の数字も読む・ブラウザでは押すとブラウザの入力欄を出す（名前の欄と同じ） |
| 落とし穴・河童の相撲の「やめる」 | 押しても同じ画面に戻るだけだった（やめられない選び方）。「やめる」を出さない |

見た目：役の大きな字・役の印・敵の状態の数・イベントの選択肢の折り返し・ショップのお守りの説明・ポーチの題・報酬の説明・結果の得点・協力の説明・図鑑の「？」・鍛冶の刻印の名前。

### 追記：「回想」は「階層」かもしれない（#245）

開発者の指摘で、「回想を進めたとき」は「階層を進めたとき」の変換かもしれない。

- 次の階層に進んだらマップが真っ暗になる不具合は 10-16 の夕方まであり、#229（10-16 22:38 のビルド）で直した。unityroom の版がそれより古ければ、これに当たっていた。
- 今の版で、ボスのマスに止まる → 戦闘 → 報酬 → ボスレリック → 次の層 → 古の神 → マップ を第1→2層・第2→3層で試し、マップが見えることを確かめた。ボス戦の途中で中断 → 続きから → 勝つ、の組み合わせも。
- そのときに見つけた、マップの戦闘専用ダイス（龍賽・大賽）の札の文字が面に重なるのを直した。ダイスの札の下の文は、長いと字を小さくする。
